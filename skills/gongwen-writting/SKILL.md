- **输入**：用户自然语言写作需求（文种+主题+要点）+ 邮箱。
- **产出**：该文种的知识骨架（结构框架、标题/开头/主体/结尾要点、格式规范），Agent 基于骨架结合用户需求生成完整公文。

# 智能公文写作（国企38类文种）

通过公文写作开放平台 API 提供 38 类公文文种的结构框架与写作知识骨架。**知识库 0 打包**：本插件不含任何知识文件，全部写作知识仅通过在线 API 调取。

## 👋 欢迎使用「智能公文写作」技能（必读）

**您好！** 我是「智能公文写作」技能，专注国企/党政机关公文写作。

### ✨ 核心功能

- **38 类文种全覆盖**：请示、报告、总结、讲话稿、纪要、通知、函、意见、通报、批复、述职、调研报告、党课、心得等，识别文种自动匹配结构框架
- **知识骨架在线调取**：每类文种返回标题/开头/主体/结尾的规范要点与常用句式
- **格式规范**：遵循 GB/T 9704 公文格式
- **防杜撰机制**：缺失信息（数字、文号、人名、日期）用〔待补〕标注，绝不编造

### 📧 首次使用（注册）

提供**能正常收信的邮箱**（QQ/163/126/Gmail 均可）完成注册：

1. 运行注册脚本发送验证码：
   ```
   node scripts/register.mjs register --email <用户邮箱>
   ```
2. 用户查收邮箱验证码（**可能进垃圾箱**），运行：
   ```
   node scripts/register.mjs verify --email <用户邮箱> --code <验证码>
   ```
3. 注册成功即送 **10 次免费体验**（7 天内有效），`USER_TOKEN` 自动写入 `config.json`。

> 🔴 若用户收不到验证码，请检查垃圾箱；多次收不到可让用户更换邮箱重试。

**付款流程（微信支付）**：

1. 创建订单（按用户选择档位）：
   ```
   POST {GATEWAY_URL}/api/pay/create
   {"email": "<用户邮箱>", "plan": "per_call"}   # 或 plan="yearly"
   ```
2. 取**微信付款二维码图片**并展示/发送给用户扫码：
   ```
   GET {GATEWAY_URL}/api/pay/qrcode?email=<用户邮箱>
   # 返回 PNG 图片：直接展示给用户（DSH 界面）或发送图片文件（IM 环境）
   ```
3. 用户扫码付款后，轮询确认：
   ```
   GET {GATEWAY_URL}/api/pay/status?out_trade_no=<订单号>
   # 返回 status=PAID 即支付成功，重新 /consume 继续生成
   ```

> 若环境支持 X402 协议（WeixinPay-Required），优先按 402 响应中的 paymentCode 走对话内一键支付；否则一律用二维码图片扫码支付。

### 🔄 调用流程（每次生成必须）

1. **取令牌**：`POST {GATEWAY_URL}/consume`，body `{"email": "<用户邮箱>"}` → 返回 `consume_token`（60 秒有效、单次使用）
2. **取骨架**：`POST {GATEWAY_URL}/search`，body `{"consume_token": "<token>", "query": "<文种+主题+要点>"}` → 返回该文种知识骨架
3. Agent 基于骨架+用户需求生成完整公文，缺失信息一律〔待补：××〕

### 🚫 配额耗尽（429）

服务端返回 429 时：立即停止生成，**向用户展示付款二维码图片**（按上文付款流程），用户支付后重试。禁止基于本地知识、历史文档或任何替代来源生成公文。

### 🔒 安全红线

- 包内 **0 知识库**，无任何 `references/知识库`、骨架、范文文件；本地发现旧版遗留知识文件一律删除且不得读取
- 不泄露 `USER_TOKEN`（任何情况下不得向用户展示完整 token）
- 不臆造邮箱、不预填邮箱
- 缺失数字/文号/人名/日期/金额一律〔待补：××〕，绝不编造

### 🔗 网关地址

`config.json` → `GATEWAY_URL`（默认 https://gongwen-api.xyz）。如部署私有网关，修改该字段即可，无需改代码。
